# Introduction

This document defines the formal code review plan for ReqStream.

## Purpose

To define review-sets and the evidence required to demonstrate that each software item has been
reviewed according to the project's compliance requirements.

## Scope

This document covers all review-sets defined in `.reviewmark.yaml` for ReqStream. The plan
encompasses C# source files, YAML requirements and configuration files, and design and
verification documentation requiring formal review. The formal review plan content is
automatically generated by the ReviewMark tool from the `.reviewmark.yaml` configuration
and review evidence store.
